# 波形测量缓存验证

本轮实测使用 Windows、GCC 15.2、Release 构建。数据集包含 1,000,000 个模拟样本，
采样时间间距 1 ms；首次统计区间为 2 至 900 s，约 898,001 个样本。
数值是单次本机测量，用于说明成本分布，不作为跨机器性能保证。

执行命令：

```powershell
cmake --build build -j 6
ctest --test-dir build --output-on-failure -j 4
.\build\tests\protoscope_wave_ui_benchmark.exe --verify --gl --capture <临时截图目录>
```

OpenGL 验证实际输出：

```text
measurement million: extract_ms=3.616 first_result_ms=86.554 stable_signature_us=0.081 synchronous_ms=74.401
```

- 首次独立输入提取：3.616 ms，仍在 UI 线程执行，随统计样本数量增长。
- 首次后台结果可用：86.554 ms，包含提取、工作线程计算、结果轮询及区间外追加后的查询。
- 稳定输入签名查询：1,000 次请求的平均耗时 0.081 微秒，没有重复提交。
- 对同一数据集执行同步区间统计：74.401 ms。此项是同步算法对照，不是旧版本整帧基准。

稳定帧只查询边界，比较通道数据代际、全局样本范围、时间轴、采样率和换算及参考参数；
不扫描或哈希区间。实际变化后才提取独立输入，后台忙时保留最新目标。
持续自动跟随使用配置间隔，间隔为 0 时也只有一个在途任务；停止后补算最终区间。

CTest 36 项全部通过。新增检查覆盖区间外追加和裁剪不重算、区间内在途追加、
同跨度不同区间、相同采样集合复用、清空重导入、通道重建、参考通道换代、
换算比例、手动参考值、时间轴变化、可视交集、持续跟随及最终收敛。
多帧 UI 检查覆盖普通与分屏的拖动释放和缩放出窗，以及原有数字通道显示；
OpenGL 验证检查截图非空，并检查了普通与分屏统计浮层截图。
